Básico

Classificar uma nota

Pede uma nota (0 a 20) ao utilizador. Usando if/elif/ else, imprime "Aprovado" se a nota for ≥ 10, "Recuperação" se estiver entre 7 (incluído) e 10 (excluído), e "Reprovado" caso contrário.

Solução

nota = float(input("Nota do aluno (0 a 20): "))

if nota >= 10:
    print("Aprovado")
elif nota >= 7:
    print("Recuperação")
else:
    print("Reprovado")

Saída esperada

Recuperação

Exemplo com nota = 8. O Python avalia as condições pela ordem em que aparecem e para na primeira que for verdadeira; por isso não é preciso repetir nota < 10 no elif.

Tabuada com range()

Pede um número inteiro ao utilizador e usa um for com range() para imprimir a sua tabuada, de 1 a 10 (por exemplo, "7 x 1 = 7").

Solução

numero = int(input("Número da tabuada: "))

for i in range(1, 11):
    print(f"{numero} x {i} = {numero * i}")

Saída esperada

7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70

range(1, 11) gera os inteiros de 1 até 10, porque em Python o limite superior de um intervalo é sempre aberto (não incluído).

Somar até ultrapassar 100

Usa um while para somar números inteiros consecutivos a partir de 1 (1, depois 1+2, depois 1+2+3…) até a soma ultrapassar 100. No final, mostra quantos números foram somados e qual foi a soma total.

Solução

soma = 0
numero = 0

while soma <= 100:
    numero += 1
    soma += numero

print("Quantidade de números somados:", numero)
print("Soma total:", soma)

Saída esperada

Quantidade de números somados: 14
Soma total: 105

1+2+…+13 = 91 (ainda ≤ 100), mas 1+2+…+14 = 105, que já ultrapassa 100 — por isso o while pára aí, com numero igual a 14.

Intermediário

Lista numerada com enumerate()

Dada ingredientes = ["farinha", "ovos", "açúcar", "manteiga"], usa for com enumerate() para imprimir uma lista numerada a partir de 1, no formato "1. farinha".

Solução

ingredientes = ["farinha", "ovos", "açúcar", "manteiga"]

for i, ingrediente in enumerate(ingredientes, start=1):
    print(f"{i}. {ingrediente}")

Saída esperada

1. farinha
2. ovos
3. açúcar
4. manteiga

enumerate() devolve pares (índice, elemento). Por defeito começa em 0, mas aceita um argumento start para começar noutro número — aqui usámos start=1 para não termos de somar 1 manualmente a cada iteração.

List comprehension: cubos pares

Usando list comprehension (numa única linha), cria uma lista com os cubos (x**3) de todos os números pares entre 0 e 20, incluindo o 20.

Solução

cubos_pares = [x**3 for x in range(21) if x % 2 == 0]

print(cubos_pares)

Saída esperada

[0, 8, 64, 216, 512, 1000, 1728, 2744, 4096, 5832, 8000]

range(21) vai de 0 a 20 (o 21 fica de fora, mas é o limite aberto do intervalo). O if dentro da comprehension filtra apenas os números pares antes de calcular o cubo.

break e continue

Dada valores = [4, 8, 15, -3, 16, 23, 42]: (a) usa for + break para percorrer a lista e parar assim que encontrar o primeiro número negativo, mostrando cada número visto até aí; (b) num novo for sobre a mesma lista, usa continue para não mostrar os múltiplos de 3.

Solução

valores = [4, 8, 15, -3, 16, 23, 42]

for v in valores:
    if v < 0:
        break
    print(v)

print("---")

for v in valores:
    if v % 3 == 0:
        continue
    print(v)

Saída esperada

4
8
15
---
4
8
16
23

No primeiro ciclo, o break interrompe tudo assim que v é negativo (-3), por isso os números seguintes nem chegam a ser vistos. No segundo, continue só salta a iteração atual: 15, -3 e 42 são múltiplos de 3 e ficam de fora, mas o ciclo continua normalmente para os restantes.

Avançado

try-except com erros específicos

Pede dois números ao utilizador e tenta dividir o primeiro pelo segundo, tratando separadamente dois erros possíveis: ValueError (o utilizador digitou algo que não é um número) e ZeroDivisionError (o segundo número é 0), cada um com a sua própria mensagem.

Solução

try:
    a = float(input("Primeiro número: "))
    b = float(input("Segundo número: "))
    print("Resultado:", a / b)
except ValueError:
    print("Erro: digite apenas números.")
except ZeroDivisionError:
    print("Erro: não é possível dividir por zero.")

Saída esperada

Erro: não é possível dividir por zero.

Usar except específicos (em vez de um único except genérico) permite dar uma mensagem mais útil, porque sabemos exatamente qual foi o problema. O Python testa cada except pela ordem em que aparece, até encontrar o tipo de erro que ocorreu.

match-case para códigos HTTP

Pede ao utilizador um código de status HTTP (inteiro) e usa match/case para mostrar a mensagem correspondente: 200 → “OK”, 301 → “Redirecionado”, 404 → “Não encontrado”, 500 → “Erro interno do servidor”, e 400 ou 401 juntos → “Pedido inválido ou não autorizado”. Qualquer outro valor deve mostrar “Código desconhecido”.

Solução

codigo = int(input("Código de status HTTP: "))

match codigo:
    case 200:
        print("OK")
    case 301:
        print("Redirecionado")
    case 404:
        print("Não encontrado")
    case 500:
        print("Erro interno do servidor")
    case 400 | 401:
        print("Pedido inválido ou não autorizado")
    case _:
        print("Código desconhecido")

Saída esperada

Não encontrado

O | dentro de um case testa vários valores de uma vez (funciona como um “ou”). O case _ final é o caso padrão, equivalente a um else, e só é executado se nenhum dos anteriores corresponder.

Dict comprehension com filtro

Dada palavras = ["sol", "computador", "python", "eu", "programação", "ia"], cria (numa linha, com dict comprehension) um dicionário que associe cada palavra com mais de 3 letras ao seu número de letras.

Solução

palavras = ["sol", "computador", "python", "eu", "programação", "ia"]

tamanhos = {palavra: len(palavra) for palavra in palavras if len(palavra) > 3}

print(tamanhos)

Saída esperada

{'computador': 10, 'python': 6, 'programação': 11}

“sol”, “eu” e “ia” têm 3 letras ou menos, por isso ficam de fora. As restantes entram no dicionário com a própria palavra como chave e o resultado de len(palavra) como valor.
