Exercícios de Python

Exercícios básicos, intermediários e avançados organizados por capítulo, para praticar o que é abordado no microcurso “AKCIT: Introdução ao Python”. Cada capítulo tem um ficheiro de exercícios e um ficheiro de respostas comentadas separado.

Como usar: tenta resolver cada exercício no teu próprio editor ou notebook antes de abrir as respostas. Os exercícios básicos assumem apenas o que já foi visto nos capítulos anteriores.
Capítulo 01

Sintaxe Básica, Variáveis e Tipos de Dados

Comentários, indentação, input/output, variáveis, tipos (int, float, str, bool), casting, operadores aritméticos e relacionais, strings, .format(), f-strings e funções built-in.

3 básico · 3 intermediário · 3 avançado
