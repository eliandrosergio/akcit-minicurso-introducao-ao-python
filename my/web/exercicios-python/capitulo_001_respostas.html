Básico

Apresentação pessoal

Cria três variáveis: nome (string), idade (inteiro) e cidade (string) com os teus próprios dados.

Depois, usa um único print() com vírgulas para exibir a frase: “<nome> tem <idade> anos e mora em <cidade>.”

Solução

nome = "Eliandro"
idade = 24
cidade = "Luanda"

print(nome, "tem", idade, "anos e mora em", cidade + ".")

Saída esperada

Eliandro tem 24 anos e mora em Luanda.

O print() insere automaticamente um espaço entre cada valor separado por vírgula (o parâmetro sep, cujo valor por defeito é ' '). Por isso juntámos cidade e "." com +, para não sobrar um espaço antes do ponto final.

As sete operações aritméticas

Pede ao utilizador dois números com input() (converte-os para float) e mostra o resultado das sete operações aritméticas do Python: soma, subtração, multiplicação, divisão, divisão inteira, resto e potenciação.

Solução

a = float(input("Primeiro número: "))
b = float(input("Segundo número: "))

print("Soma:", a + b)
print("Subtração:", a - b)
print("Multiplicação:", a * b)
print("Divisão:", a / b)
print("Divisão inteira:", a // b)
print("Resto:", a % b)
print("Potenciação:", a ** b)

Saída esperada

Soma: 13.0
Subtração: 7.0
Multiplicação: 30.0
Divisão: 3.3333333333333335
Divisão inteira: 3.0
Resto: 1.0
Potenciação: 1000.0

Exemplo com a = 10 e b = 3. Repara que, como convertemos a e b para float, mesmo a divisão inteira (//) devolve um resultado do tipo decimal (3.0 em vez de 3).

Descobrir o tipo de cada variável

Cria quatro variáveis: uma int, uma float, uma str e uma bool, cada uma com um valor à tua escolha. Usa a função type() para mostrar o tipo de cada uma.

Solução

numero = 10
decimal = 3.14
texto = "Python"
verdadeiro = True

print(type(numero))
print(type(decimal))
print(type(texto))
print(type(verdadeiro))

Saída esperada

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

Em Python não é preciso declarar o tipo de uma variável: o interpretador decide o tipo a partir do valor atribuído. A função type() permite confirmar esse tipo em qualquer altura.

Intermediário

Cálculo dentro da f-string

Cria uma variável idade com a tua idade atual. Usando f-string, escreve numa única linha uma frase que diga quantos anos terás daqui a 10 anos, fazendo o cálculo dentro das chavetas {} da própria f-string (sem calcular numa variável separada antes).

Solução

idade = 24
print(f"Tenho {idade} anos. Daqui a 10 anos terei {idade + 10} anos.")

Saída esperada

Tenho 24 anos. Daqui a 10 anos terei 34 anos.

Dentro de uma f-string, qualquer expressão Python válida colocada entre {} é calculada antes de o texto final ser montado — incluindo operações aritméticas, como idade + 10.

Prevê a saída: == contra is

Sem executar, diz o que será impresso em cada uma das quatro linhas abaixo e explica porquê. Depois corre o código para confirmar.

a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a == b)
print(a is b)
print(a is c)
print(b == c)

Solução

a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)   # compara valores
print(a is b)   # compara identidade (mesmo objeto?)
print(a is c)
print(b == c)

Saída esperada

True
False
True
True

== compara valores; is compara se duas variáveis apontam para o mesmo objeto na memória. a e b têm valores iguais, mas foram criadas de forma independente — por isso a is b é False. Já c = a não cria uma cópia: apenas dá um segundo nome ao mesmo objeto, por isso a is c é True. Como b e c têm o mesmo valor, b == c também é True.

Par ou ímpar, sem usar if

Pede um número inteiro ao utilizador. Sem usar if (as condicionais são o assunto do próximo capítulo), guarda o resultado de uma comparação relacional com o operador % numa variável booleana eh_par, e mostra uma frase com f-string que use essa variável diretamente dentro do texto.

Solução

numero = int(input("Digite um número inteiro: "))
eh_par = numero % 2 == 0
print(f"O número {numero} é par? {eh_par}")

Saída esperada

O número 7 é par? False

numero % 2 calcula o resto da divisão por 2; se o resto for 0, o número é par. O operador relacional == compara esse resto com 0 e devolve diretamente True ou False, que guardamos em eh_par.

Avançado

Área e perímetro com formatação

Uma pizzaria quer calcular a área e o perímetro (circunferência) de pizzas redondas. Pede ao utilizador o raio da pizza em cm e, usando a biblioteca math e f-strings com formatação de duas casas decimais (:.2f), mostra a área (π·r²) e o perímetro (2·π·r).

Solução

import math

raio = float(input("Raio da pizza em cm: "))
area = math.pi * raio ** 2
perimetro = 2 * math.pi * raio

print(f"Área: {area:.2f} cm²")
print(f"Perímetro: {perimetro:.2f} cm")

Saída esperada

Área: 706.86 cm²
Perímetro: 94.25 cm

Exemplo com raio = 15. A notação :.2f dentro da f-string formata um número decimal com exatamente duas casas depois da vírgula — é diferente de arredondar antes; a formatação acontece só na hora de exibir.

Troco em notas, só com // e %

Um multibanco só tem notas de 2000, 1000, 500 e 100 Kz. Escreve um programa que recebe um valor inteiro em Kz (via input()) e calcula quantas notas de cada valor serão entregues, usando apenas divisão inteira (//) e resto (%) em cadeia — sem usar if nem ciclos.

Solução

valor = int(input("Valor a levantar (Kz): "))

notas_2000 = valor // 2000
resto = valor % 2000
notas_1000 = resto // 1000
resto = resto % 1000
notas_500 = resto // 500
resto = resto % 500
notas_100 = resto // 100
resto_final = resto % 100

print(f"Notas de 2000: {notas_2000}")
print(f"Notas de 1000: {notas_1000}")
print(f"Notas de 500: {notas_500}")
print(f"Notas de 100: {notas_100}")
print(f"Valor que não é possível entregar: {resto_final} Kz")

Saída esperada

Notas de 2000: 1
Notas de 1000: 1
Notas de 500: 1
Notas de 100: 2
Valor que não é possível entregar: 50 Kz

Exemplo com valor = 3750. A cada passo, // dá quantas notas cabem naquele valor, e % dá o que sobra para o passo seguinte — a mesma lógica usada por caixas eletrónicos reais.

A mesma frase de três formas

Dado nome = "Eliandro" e linguagem = "Python", escreve a mesma frase “Eliandro está a aprender Python.” de três formas diferentes: (1) concatenação com +; (2) o método .format() com índices posicionais; (3) f-string. No final, usa o operador == para confirmar que as três strings resultantes são idênticas.

Solução

nome = "Eliandro"
linguagem = "Python"

frase1 = nome + " está a aprender " + linguagem + "."
frase2 = "{0} está a aprender {1}.".format(nome, linguagem)
frase3 = f"{nome} está a aprender {linguagem}."

print(frase1)
print(frase2)
print(frase3)
print(frase1 == frase2 == frase3)

Saída esperada

Eliandro está a aprender Python.
Eliandro está a aprender Python.
Eliandro está a aprender Python.
True

As três abordagens produzem exatamente a mesma string, por isso a comparação encadeada frase1 == frase2 == frase3 devolve True. Desde o Python 3.6, as f-strings costumam ser a forma mais legível e direta das três.
