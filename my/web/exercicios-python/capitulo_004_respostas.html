Básico

Função sem parâmetros nem retorno

Cria uma função boas_vindas() que não recebe parâmetros nem devolve valor, apenas imprime "Bem-vindo(a) ao curso de Python!". Chama a função duas vezes.

Solução

def boas_vindas():
    print("Bem-vindo(a) ao curso de Python!")

boas_vindas()
boas_vindas()

Saída esperada

Bem-vindo(a) ao curso de Python!
Bem-vindo(a) ao curso de Python!

Mesmo sem parâmetros, os parênteses () são obrigatórios tanto na declaração como na chamada da função.

Área do retângulo

Cria uma função area_retangulo(base, altura) que recebe dois parâmetros e devolve a área do retângulo. Chama-a com base=5 e altura=3, e exibe o resultado.

Solução

def area_retangulo(base, altura):
    return base * altura

resultado = area_retangulo(5, 3)
print(f"A área é {resultado} m².")

Saída esperada

A área é 15 m².

Uma função com return devolve o valor calculado, mas não o imprime sozinha — por isso guardamos o retorno em resultado antes de o exibir.

Menor e maior com parâmetros nomeados

Cria uma função min_max(n1, n2) que devolve dois valores: o menor e o maior dos dois números recebidos. Chama-a passando os parâmetros por nome, na ordem invertida (n2= primeiro, n1= depois), e guarda os dois retornos em variáveis separadas.

Solução

def min_max(n1, n2):
    menor = n1 if n1 < n2 else n2
    maior = n1 if n1 > n2 else n2
    return menor, maior

pequeno, grande = min_max(n2=10, n1=25)
print("Menor:", pequeno)
print("Maior:", grande)

Saída esperada

Menor: 10
Maior: 25

Quando os parâmetros são passados por nome (n2=10, n1=25), a ordem em que aparecem na chamada deixa de importar — o Python liga cada valor ao nome do parâmetro correspondente. Uma função pode devolver vários valores separados por vírgula; ao chamá-la, é preciso uma variável para cada um.

Intermediário

Média com *args

Cria uma função media(*notas) que aceita uma quantidade variável de notas e devolve a média delas. Testa com 3 e depois com 4 notas.

Solução

def media(*notas):
    return sum(notas) / len(notas)

print(media(15, 18, 12))
print(media(10, 10, 10, 10))

Saída esperada

15.0
10.0

O * antes de notas recebe qualquer quantidade de argumentos posicionais como uma tupla, por isso a mesma função funciona com 3, 4 ou qualquer outro número de notas.

Lambda + map(): Celsius para Fahrenheit

Dada temperaturas_c = [0, 10, 20, 30, 100], usa map() com uma função lambda para converter todas as temperaturas para Fahrenheit (F = C * 9/5 + 32).

Solução

temperaturas_c = [0, 10, 20, 30, 100]

temperaturas_f = list(map(lambda c: c * 9 / 5 + 32, temperaturas_c))

print(temperaturas_f)

Saída esperada

[32.0, 50.0, 68.0, 86.0, 212.0]

map(funcao, lista) aplica funcao a cada elemento da lista e devolve um iterável — por isso envolvemos o resultado em list() para o ver como lista.

Lambda + filter(): palavras longas

Dada palavras = ["sol", "computador", "eu", "python", "ia", "programação"], usa filter() com uma função lambda para obter apenas as palavras com mais de 5 letras.

Solução

palavras = ["sol", "computador", "eu", "python", "ia", "programação"]

longas = list(filter(lambda p: len(p) > 5, palavras))

print(longas)

Saída esperada

['computador', 'python', 'programação']

filter(funcao, lista) mantém apenas os elementos para os quais a função devolve True. Aqui, a lambda testa se o comprimento da palavra é maior que 5.

Avançado

Ficha de cadastro com **kwargs

Cria uma função ficha_cadastro(**dados) que recebe qualquer quantidade de campos nomeados e devolve uma única string com um campo por linha, no formato "campo: valor".

Solução

def ficha_cadastro(**dados):
    linhas = []
    for campo, valor in dados.items():
        linhas.append(f"{campo}: {valor}")
    return "\n".join(linhas)

print(ficha_cadastro(nome="Marta", idade=30, cidade="Benguela"))

Saída esperada

nome: Marta
idade: 30
cidade: Benguela

**dados recebe os parâmetros nomeados como um dicionário, por isso usamos .items() para percorrer os pares campo-valor. "\n".join(linhas) junta a lista de linhas numa só string, separada por quebras de linha.

Prevê a saída: UnboundLocalError

Prevê a saída deste código e explica o papel do comando global. O que aconteceria se, dentro de incrementar_global, a linha global contador fosse removida?

contador = 0

def incrementar_global():
    global contador
    contador = contador + 1
    print(contador)

incrementar_global()
incrementar_global()
print(contador)

Solução

contador = 0

def incrementar_global():
    global contador
    contador = contador + 1
    print(contador)

incrementar_global()  # 1
incrementar_global()  # 2
print(contador)       # 2

Saída esperada

1
2
2

global contador avisa o Python que qualquer atribuição a contador dentro desta função deve afetar a variável global, e não criar uma variável local nova. Sem essa linha, como a função faz uma atribuição a contador (contador = contador + 1), o Python passa a tratar contador como local em toda a função — e a leitura do lado direito falharia com UnboundLocalError: local variable 'contador' referenced before assignment, porque essa variável local ainda não tinha sido definida.

Uma função como parâmetro

Cria uma função melhor_valor(*valores, criterio) que recebe uma quantidade variável de números e uma função de critério (por exemplo, as funções built-in max ou min) passada por nome, e devolve o resultado de aplicar esse critério aos valores recebidos.

Solução

def melhor_valor(*valores, criterio):
    return criterio(valores)

notas = [14, 9, 18, 12]
print(melhor_valor(*notas, criterio=max))
print(melhor_valor(*notas, criterio=min))

Saída esperada

18
9

Como criterio vem depois de *valores, o Python exige que seja sempre passado por nome (é um “parâmetro exclusivamente nomeado”). Passar max ou min como argumento funciona porque, em Python, funções são valores como quaisquer outros e podem ser guardadas em variáveis ou passadas para outras funções. O *notas na chamada desempacota a lista em argumentos posicionais separados.
