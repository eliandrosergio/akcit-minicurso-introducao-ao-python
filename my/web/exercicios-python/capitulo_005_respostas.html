Básico

Criar um arquivo de notas

Cria a lista notas = ["Matemática: 16", "Português: 14", "Informática: 18"] e escreve cada item numa linha separada de um arquivo chamado notas.txt, usando with e o modo "w".

Solução

notas = ["Matemática: 16", "Português: 14", "Informática: 18"]

with open("notas.txt", "w") as arquivo:
    for linha in notas:
        arquivo.write(linha + "\n")

Saída esperada

(sem saída no ecrã — o arquivo notas.txt é criado com 3 linhas)

O modo "w" cria o arquivo se ele não existir, e apaga todo o conteúdo anterior se já existir. write() não acrescenta quebras de linha sozinho, por isso somamos "\n" a cada linha.

Mostrar o conteúdo de um arquivo

Escreve uma função mostrar_conteudo(caminho) que abre o arquivo em modo de leitura e imprime todo o seu conteúdo, usando with.

Solução

def mostrar_conteudo(caminho):
    with open(caminho, "r") as arquivo:
        conteudo = arquivo.read()
        print(conteudo)

mostrar_conteudo("notas.txt")

Saída esperada

Matemática: 16
Português: 14
Informática: 18

with open(...) as arquivo garante que o arquivo é sempre fechado corretamente no final do bloco, mesmo que ocorra um erro durante a leitura.

Adicionar sem apagar (append)

Usando o modo "a", adiciona a linha "Inglês: 17" ao final de notas.txt, sem apagar o conteúdo já existente. Depois, mostra o conteúdo atualizado.

Solução

with open("notas.txt", "a") as arquivo:
    arquivo.write("Inglês: 17\n")

mostrar_conteudo("notas.txt")  # reaproveitando a função do exercício anterior

Saída esperada

Matemática: 16
Português: 14
Informática: 18
Inglês: 17

Ao contrário do modo "w", o modo "a" (append) escreve sempre a partir do final do arquivo, preservando o que já lá estava.

Intermediário

Contar linhas de um arquivo

Escreve uma função contar_linhas(caminho) que devolve quantas linhas o arquivo tem, usando readlines() e len().

Solução

def contar_linhas(caminho):
    with open(caminho, "r") as arquivo:
        return len(arquivo.readlines())

print(contar_linhas("notas.txt"))

Saída esperada

4

readlines() devolve uma lista com uma string por linha do arquivo; len() dessa lista dá o número total de linhas.

Contar ocorrências de uma palavra

Escreve uma função contar_palavra(caminho, palavra) que conta quantas vezes uma palavra aparece no arquivo, usando .split() e .count().

Solução

def contar_palavra(caminho, palavra):
    with open(caminho, "r") as arquivo:
        conteudo = arquivo.read()
    palavras = conteudo.split()
    return palavras.count(palavra)

print(contar_palavra("notas.txt", "Matemática:"))

Saída esperada

1

.split() divide o texto em espaços em branco, mantendo a pontuação colada à palavra — por isso a busca é por "Matemática:" (com dois pontos), não apenas "Matemática".

Linhas de um arquivo numa lista, sem \n

Escreve uma função linhas_para_lista(caminho) que lê o arquivo e devolve uma lista com cada linha, mas sem a quebra de linha (\n) no final de cada elemento.

Solução

def linhas_para_lista(caminho):
    with open(caminho, "r") as arquivo:
        linhas = arquivo.readlines()
    return [linha.strip() for linha in linhas]

print(linhas_para_lista("notas.txt"))

Saída esperada

['Matemática: 16', 'Português: 14', 'Informática: 18', 'Inglês: 17']

readlines() mantém o \n no fim de cada linha; .strip() remove espaços em branco e quebras de linha das pontas de cada string. A list comprehension aplica .strip() a cada linha de uma só vez.

Avançado

Tratar arquivo inexistente

Escreve uma função mostrar_conteudo_seguro(caminho) que tenta mostrar o conteúdo de um arquivo e, se ele não existir, mostra uma mensagem amigável em vez de o programa terminar com um erro.

Solução

def mostrar_conteudo_seguro(caminho):
    try:
        with open(caminho, "r") as arquivo:
            print(arquivo.read())
    except FileNotFoundError:
        print(f"O arquivo '{caminho}' não foi encontrado.")

mostrar_conteudo_seguro("arquivo_que_nao_existe.txt")

Saída esperada

O arquivo 'arquivo_que_nao_existe.txt' não foi encontrado.

Tentar abrir um arquivo que não existe lança um FileNotFoundError. Ao capturar essa exceção especificamente, conseguimos dar uma resposta clara em vez de deixar o programa parar com um traceback.

Calcular e gravar a média

O arquivo notas_numericas.txt tem um número por linha. Escreve uma função calcular_e_gravar_media(entrada, saida) que lê essas notas, calcula a média (com 2 casas decimais) e grava o resultado num novo arquivo.

Verificar se um arquivo está em uso

Escreve uma função arquivo_em_uso(caminho) que tenta detetar se um arquivo está a ser usado por outro processo, tentando renomeá-lo para ele mesmo com os.rename() e capturando o erro correspondente.

Solução

import os

def arquivo_em_uso(caminho):
    try:
        os.rename(caminho, caminho)
        return False
    except OSError:
        return True

if not arquivo_em_uso("notas.txt"):
    with open("notas.txt", "a") as arquivo:
        arquivo.write("Física: 15\n")
else:
    print("O arquivo está em uso, tenta novamente mais tarde.")

Saída esperada

(depende do estado real do arquivo no teu sistema)

A maioria dos sistemas operativos não permite renomear um arquivo que está a ser usado por outro processo. Tentar renomeá-lo para o próprio nome é uma forma indireta de testar isso: se falhar com OSError, é porque está em uso.
